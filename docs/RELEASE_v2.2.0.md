# Chefish v2.2.0

这次更新集中打磨界面、菜谱标签和首次使用体验。

## 主要更新

- **更清爽的厨房界面**：统一明亮橙色、浅绿辅助色和思源黑体，调整首页、菜谱卡片、库存、周历、采购与设置的布局和密度。
- **按自己的习惯开始**：新增可跳过的初始化流程，配置模型、描述并核对饮食偏好、选择常吃菜系、启用管家和连接云账户。之后可在通用设置中重新开启。弹窗全程保持一致尺寸，长内容独立滚动，切页更舒缓，并修复进入和切页时的闪回。
- **统一的菜谱标签**：菜系、菜品特性、烹饪方法、自定义四类分别配色，支持层级筛选、批量开关及自定义。管家统一从标签目录中选择；用户可允许助手自动开启匹配的未启用标签。
- **本地彩色食材图标**：常见食材使用本地图形，缺图时显示名称首字；用户明确选择的图片优先。来源与许可可在关于页面查看。
- **更顺手的日常操作**：周灵感按周独立保存；早餐默认隐藏，午晚餐默认显示，均可调整。优化菜单拖放与提醒横栏；库存可手动修改单位，烹饪实际用量优先遵循用户记录。
- **更简洁的采购清单**：数量最多显示一位小数，已购项目默认隐藏，采购备忘自动保存。

## 下载与升级

- `Chefish_2.2.0_x64-setup.exe`：Windows x64 安装包，适合大多数用户。
- `chefish.exe`：独立程序，需要 Windows WebView2 运行环境。

升级前可在「我的厨房 → 数据与备份」保存一份本地备份。本版数据库结构升级至 schema 18。

**云端状态**：源码中的兼容规则已更新并通过本地模拟器检查，但生产 Firebase 规则尚待部署。本版云同步暂不能视为已就绪，本地功能可独立使用。

本次已完成 TypeScript、ESLint、前端与 Rust 测试、浏览器交互回归及 Windows EXE／NSIS 构建。具体范围见仓库中的 `docs/release-v2.2.0.json`；本次未做生产云端部署或覆盖安装验收。
