# v1.0.0 当前开发状态

更新：2026-10-26。目标为单用户 Windows 桌面应用，中文优先。以下包含当前工作区新增的设置与备份功能，公开发行版尚未更新。项目版本与数据库结构版本独立；当前数据库为 schema 14，升级前保存一致备份。

## 已实现

| 范围 | 当前能力 |
|---|---|

| 图片与用量 | 封面/步骤图可上传、替换、移除与放大查看，AI 可辅助寻找参考封面，图片保存到配方版本；精确量与原文量统一展示；食材与调料分类可纠正 |
| 厨房手记 | 新增、独立弹窗编辑、删除；与库存消耗分开 |
| 批次库存 | 默认隐藏已用完；列表内加减/输入数量、直接下拉切库位；详情编辑日期与分类；标签复选筛选、固定列宽；删除二次确认，历史保留；支持常见食材自动分类 |
| 调料 | 独立侧栏、缺货优先、感叹号切换、删除及重新添加、首页与采购提醒 |

| 采购 | 按餐次时间线计算需求与库存分配；手动项目、购买入库、备忘、复制清单及调料提醒 |
| 烹饪 | 当天及过去餐次可完成；优先文字记录，AI 整理实际用量后事务扣减；手动调整、独立手记、重启查看与整次撤销 |
| 数据备份 | 支持手动 SQLite 一致快照、每日启动自动快照、恢复内容预览及恢复前安全备份；菜谱图片随数据库保存，恢复通过 SQLite 在线备份写入 |

| AI | DeepSeek 为主，OpenAI / Gemini 适配；真实站内检索、整理导入、本地查询、类型化提案、同意 / 拒绝 / 对话调整 |

采购不再要求用户核对用量。常见名称按共享词表统一，例如蒜末/蒜头/大蒜、番茄/西红柿、意面/Spaghetti；切法仍保留在来源和步骤中。克/千克、毫升/升等明确单位直接换算；按个、瓣或包装换算为重量时采用常见规格估算，未掌握实际包装净重时不称为精确测量。旧库存不改 ID 或历史，采购与烹饪通过别名和换算系数匹配。少许、半个等原文量由已配置的 AI 后台整理并缓存；服务暂不可用时保留原文并静默续试。

完成烹饪分别填写实际用了什么和口味、火候手记。直接确认会先整理文字记录，少许按人数与菜谱估计，没提到的食材不额外扣减；也可展开手动调整。仅扣除实际存在且未超过剩余量的批次，未入库食材保留在文字中。手记同步写入对应菜谱笔记。

粗略数量和未填写到期日作为普通库存参与采购与烹饪，不额外标警；仅明确过期批次排除。正常采购在确认数量、位置和日期后同时入库。用户只说“买好了、帮我勾掉”时，AI 可先记录购买事实，后续完善收货信息；不会凭空填写库位和有效期。

库存照片在启动、购买及联网后后台补齐，使用已配置的模型服务，无需逐项操作。模型生成准确搜索词并筛选 Wikimedia Commons 候选，程序下载、白底缩放为 192×192 JPEG，按食材共用并保存来源和署名。详情可“让 AI 换张图片”，也可向厨房助手说明换图偏好。未找到合适照片时暂显示食材首字，不打断操作；离线仍可显示已保存图片。模型请求按原有服务计费，缺图任务会批量处理并缓存。

常备调料同样自动补图，名称与库存字号一致。头像带留白完整显示；调料可点击头像换图、右键查看来源与许可。行内数量修改立即反馈并使用轻量库存结果更新，数据库调用在后台执行。侧栏双击外部可关闭，单击外部仍保留当前编辑。

全局导航支持返回按钮与 Alt+←，保留页面和菜谱详情访问历史。全局撤销支持升级后在本机保存的厨房操作，通过顶部按钮或 Ctrl+Z 使用；输入框保留文字撤销。首页下一餐按本机时间选择：10 点前早餐、14 点前午餐、21 点前晚餐，排除已完成菜品，跨天显示日期。

返回按钮固定在顶部并显示“返回”文字，新页面从顶部打开，返回恢复离开前的滚动位置。步骤图上传紧跟对应做法，展示时横图在下、竖图在右，并支持放大。同一餐有多道未完成菜时，首页默认展示前两道，其余显示数量。

## 当前限制

- 原文量不自动折算成克数，也不进入精确库存计算。个、片等单位不能无依据地换算重量。
- 普通食材名称匹配有限；调料常见品牌和拼写别名已作部分归并。
- AI 无任意 SQL、系统命令或文件操作权限；新建对象后引用新 ID 的动作目前需分开提案。
- DeepSeek 已作真实模型交互验证，OpenAI / Gemini 尚不能概括为完整实测通过。
- 第三方站点响应决定导入成功率，检索结果不保证覆盖全站。
- 菜谱删除后历史引用保留；没有通用回收站或所有操作的全量撤销。
- Windows x64 NSIS 安装包已构建并发布；升级、卸载与数据保留仍待专项验收。完整导出与自动更新尚未实现。
- 同行修改保守暂停，由用户选择保留云端；尚无逐字段冲突编辑器、云端容量管理与历史压缩。两台实体电脑、真实邮箱与长期网络场景仍需实际观察。没有英文界面或程序退出后的系统提醒。
