# v1.0.0 当前开发状态

更新：2026-10-25。目标为单用户 Windows 桌面应用，中文优先。以下包含当前工作区新增的设置与备份功能，公开发行版尚未更新。项目版本与数据库结构版本独立；当前数据库为 schema 11。

## 已实现

| 范围 | 当前能力 |
|---|---|
| 菜谱 | 创建、编辑、JSON / 下厨房链接 / HTML 导入、重复来源处理、分类排序、收藏、周灵感、配方版本与历史恢复编辑 |
| 图片与用量 | 封面和步骤图本机保存；精确量与原文量统一展示；食材与调料分类可纠正 |
| 厨房手记 | 新增、独立弹窗编辑、删除；与库存消耗分开 |
| 批次库存 | 数量、库位、购买日、可空到期日；使用、丢弃、校正、转移、操作历史及受版本保护的撤销 |
| 调料 | 独立侧栏、缺货优先、感叹号切换、删除及重新添加、首页与采购提醒 |
| 周菜单 | 跨周、同餐多菜、拖动和表单安排、份数调整、临时菜名、移除、绑定配方版本 |
| 采购 | 按餐次时间线计算需求与库存分配；手动项目、购买入库、备忘、复制清单及调料提醒 |
| 烹饪 | 当天及过去餐次可完成；核对实际用量后事务扣减，保留记录与整次撤销 |
| 数据备份 | 支持手动 SQLite 一致快照、每日启动自动快照、恢复内容预览及恢复前安全备份；菜谱图片随数据库保存，恢复通过 SQLite 在线备份写入 |
| AI | DeepSeek 为主，OpenAI / Gemini 适配；真实站内检索、整理导入、本地查询、类型化提案、同意 / 拒绝 / 对话调整 |
| 对话与配置 | 本机聊天保留和清除，Enter 发送、Shift+Enter 换行，模型配置及 Windows 凭据存储 |
| 厨房设置 | 左下角“我的厨房”打开统一设置；默认人数联动展示和新配餐，支持自由文本口味、忌口、厨具偏好，启动页及发送按键；详见 [设置说明](SETTINGS.md) |
| 批次日期 | AI 可修改已有批次到期日；明确授权估计时展示依据，保留原数量和购买日期，可撤销 |

正常采购在确认数量、位置和日期后同时入库。用户只说“买好了、帮我勾掉”时，AI 可先记录购买事实，后续完善收货信息；不会凭空填写库位和有效期。

## 当前限制

- 原文量不自动折算成克数，也不进入精确库存计算。个、片等单位不能无依据地换算重量。
- 普通食材名称匹配有限；调料常见品牌和拼写别名已作部分归并。
- AI 无任意 SQL、系统命令或文件操作权限；新建对象后引用新 ID 的动作目前需分开提案。
- DeepSeek 已作真实模型交互验证，OpenAI / Gemini 尚不能概括为完整实测通过。
- 第三方站点响应决定导入成功率，检索结果不保证覆盖全站。
- 菜谱删除后历史引用保留；没有通用回收站或所有操作的全量撤销。
- Windows x64 NSIS 安装包已构建并发布；升级、卸载与数据保留仍待专项验收。完整导出与自动更新尚未实现。
- 无多用户、云同步、英文界面或程序退出后的系统提醒承诺。

后续范围见 [路线图](ROADMAP.md)。测试与真实桌面检查分别记录，不将浏览器演示通过等同于完整原生验收。
