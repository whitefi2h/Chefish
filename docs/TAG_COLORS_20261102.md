# 四类标签颜色与菜谱卡片微调

颜色来自共享变量，不修改标签数据、目录、筛选或其他业务逻辑。

| Before | After | Why |
| --- | --- | --- |
| 菜系、特性部分区分，方法与自定义使用灰色 | 菜系浅橙、特性浅绿、方法浅蓝、自定义浅紫，均使用深色文字 | 让四类信息可以快速区分，并保留文字名称 |
| 选择器及筛选中的标签没有统一类别色 | 卡片、详情、选择按钮、已选筛选、上级已选项使用同一类别变量 | 同一标签跨场景保持一致 |
| 4:3 菜谱封面 | 8:5 封面，高度约减少 17% | 保留图片重点，减少纵向占用 |
| 内容及底部按钮带来较多纵向留白，缺标签卡片底部更高 | 收紧内边距、底部按钮内边距；标签使用整行，底部按同排卡片对齐 | 协调单行、双行菜名与不同数量标签 |

四列／三列判断、菜名右侧周灵感入口、收藏、筛选和详情流程保持原样。

验证：TypeScript、ESLint、生产构建通过；标签及菜谱浏览器回归 12 项通过，包括四类选择／详情颜色一致性、标签创建筛选与撤销，以及 1000、1280、1440、1920 的列数和卡片检查。最后调整底部对齐后，四种宽度的菜谱回归再次通过。截图是隔离演示数据，非个人厨房实机验收。
