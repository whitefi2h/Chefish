# 设置分组与局部排版微调

依据用户 2026-11-03 的三张实机批注，沿用现有字体、颜色和功能，只修改展示。

| Before | After | Why |
| --- | --- | --- |
| 菜谱卡片数字人份视觉上偏左 | 人份文字向右补偿 2px | 平衡数字与中文标题左侧字面留白，不移动标题和标签 |
| 首页下一餐图片 260px，窄窗口 230px | 分别缩为 228px、214px，垂直居中 | 减轻主图纵向占用，保持与右侧面板的统一布局 |
| 下一餐用时、人份继承 15px 正文 | 独立设为 13px、行高 1.4，时钟图标 14px | 让辅助信息与菜名形成明确层级 |
| 管家选项连成一片，原生小勾选框不易定位 | 分为运行与通知、每周菜单、日常整理、新菜谱与灵感四组；组内用细线分隔，沿用设置页的滑动开关 | 明确选项边界和开关归属 |
| 标题、说明字重接近，时间控件分散 | 选项标题 14px/Medium、说明 13px/Regular；时间和日期并排，常做餐次单列一行 | 降低文字压迫感，统一行对齐与控件密度 |
| 设置页大标题和间距偏大 | 大标题从 28px 收为 24px，收紧内边距；相邻选项增加分隔线 | 与其他设置页保持一致，并让内容更早进入首屏 |

管家调度、通知、自动开启标签、偏好、备份、云同步及保存流程均未修改。开关仍使用原有状态和提交逻辑；保留键盘焦点及减少动画设置。
