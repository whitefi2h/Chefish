# 菜谱卡片与导入标签收紧

本轮只调整展示层，沿用原有列数、封面比例、标签颜色和业务流程。

| Before | After | Why |
| --- | --- | --- |
| 标题、标签与底部信息之间留白偏多 | 内容上下内边距收至 10px，标签与标题间隔 5px，标签高度 20px | 将信息组织成紧凑的一组，减少卡片文字区占用 |
| 周灵感按钮和底部查看按钮撑高文字区 | 周灵感按钮高度 28px，底部按钮最小高度 22px | 保留入口辨识度，同时压缩控件带来的空隙 |
| 不同卡片内容长度造成底部参差 | 同排卡片底部继续对齐，菜名允许换行 | 兼顾长菜名和横向浏览的整齐感 |
| 导入草稿展开全部可用标签 | 默认只显示已选标签，点击“修改标签”才展开搜索与选项 | 避免标签目录挤占配方编辑空间 |
| 收起后无法直接查看选择 | 已选标签以原类别色保留在摘要行 | 无需展开即可核对；展开、修改、收起不会丢失选择 |

普通创建、编辑菜谱的标签选择器仍沿用原布局；导入草稿顶部确认按钮保持可用。

## 验证

- TypeScript、ESLint、生产构建及 Windows NSIS 构建通过。
- 浏览器回归 20 项中 19 项通过，包括标签选择、创建与筛选、导入编辑保存，以及 1000、1280、1440、1920 宽度检查。折叠标签交互单独复测通过。
