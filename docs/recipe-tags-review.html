开启，是显示选择

只有开启项进入常用筛选和编辑候选；已标注的隐藏标签保留，可从完整目录重新开启。

菜系支持向上检索

只标“川菜”，也能被“中餐”筛出。不必在卡片上把父级全部重复显示。

三个类型可以组合

同一类型多选为“或”；跨类型为“且”。如中餐 + 快手菜 + 炒。

目录来源与本轮范围

标签名称交叉参考菜谱平台、厨师技法指南和地方菜系资料。默认开关、词条归组、别名及检索层级是 Chefish 的产品设计。目录不是排他的世界菜系谱系。
