本版包含自 v2.2.0 以来的累计更新。

- **主动消息收纳**：助手顶部固定入口与未读数字红点，待处理消息集中查看，长会话无需滚回顶部；关闭列表保留聊天位置和输入草稿。
- **同步修复与强制替换**：偏好按字段合并，普通记录和设置自动合并；无法合并时可明确选择“以本机版本替换云端”或“以云端版本替换本机”。替换前自动备份，旧云端基准保留恢复记录。
- **软件内更新**：关于 Chefish 提供新版本提示、自动下载开关、手动检查和安装，以及 GitHub 入口。自动下载默认关闭，下载后由用户确认重启安装；更新包带签名校验。
- **库存提醒一致**：首页与库存页共用范围、临期筛选和到期排序，修复首页多出条目和计数不一致。

升级前请完全退出旧程序（包括托盘），保存需要的本机备份。各同步设备均应更新。若当前电脑的内容应作为完整版本，在“设置 → 账户与云端 → 强制替换同步版本”选择以本机替换云端；其他设备确认后再以云端替换本机。此操作会采用选定的完整版本，请留意覆盖方向。

数据库仍为 schema 18，所需生产 Firebase 规则已部署。隔离双库的 135 项冲突队列恢复、真实 Firebase 临时账户替换与重新连接测试通过；首页/库存及长会话主动消息场景通过浏览器隔离验证。本次未访问个人厨房、实际同步队列或个人聊天；实际安装升级及两台实体电脑长期验收仍由使用中确认。

下载 Windows x64 安装包，或使用独立 EXE。`latest.json` 与 `.sig` 用于软件内更新。v2.2.x 及更早版本请先手动安装本版；v2.3.0 起可在“设置 → 关于 Chefish”检查更新。
