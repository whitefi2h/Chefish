# 菜系精简、自动开启和助手图标修复

2026-11-02，本地版本仍为 2.0.0。

- 菜系预设从 46 减至 40。删除中餐三级预设淮扬菜、潮州菜，以及东南亚菜下面的五个国家细分预设；中餐、西餐之外的根菜系统一收进“异国风味”。默认开启总数仍为 24。
- 新增独立“自定义”类型，可新增、检索、筛选、批量开关和选择菜谱标签；已有三类仍允许添加自建词条。
- 设置 → 厨房管家 → 日常整理新增“允许助手自动开启标签”，默认关闭。开关按现有管家设置保存；整理请求携带开关值，模型从已有未删除目录选择标签。后端在同一整理事务中开启匹配项并关联菜谱，复用同步日志与撤销。人工标注优先，已删除标签不会恢复，也不会自动创建标签。
- 助手头部的历史、设置、更多三个按钮原来宽 30px 却继承左右各 14px 内边距，压缩 SVG；已归零图标按钮内边距并禁止 SVG 收缩。

数据库 schema 17 → 18，在现有安全备份后迁移。被移除的内置标签关联归到上级：淮扬菜 → 苏菜、潮州菜 → 粤菜，东南亚细分 → 东南亚菜。保留用户自建词条、其他开关和菜谱内容。

验证：TypeScript、ESLint、生产构建通过；Rust 常规测试 156 passed / 1 ignored（排除 live 与 firestore），随后新增的目录升级迁移和自动开启／关闭／重启／撤销／人工优先测试分别通过。浏览器标签与管家既有流程 20 项通过，新增目录／自定义、设置保存、三种宽度图标尺寸检查共 5 项通过。前端单元 36 passed / 1 skipped；Firestore 本地模拟器 8 项通过，允许 schema 18 并拒绝未来版本。
