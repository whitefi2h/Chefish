# 实机批注修正

2026-11-01。本轮以用户七张截图的批注为准。

| Before | After | Why |
| --- | --- | --- |
| 菜名下方显示管家标签串 | 从菜谱卡片移除标签串，底层标签数据保留 | 避免重复分类与无明确作用的信息 |
| 分类按钮独占第二行且高度偏大 | 搜索、显示已用完、管理分类、自动分类、清除筛选归入标题工具行；分类按钮高 32px | 落实工具上移，完整位置／类别筛选继续位于列表上方；窄窗口允许工具换行 |
| 库存数量、日期与状态使用 14px | 三项改为 13.5px | 按批注减小 0.5px，不改变名称和行内编辑行为 |
| 周切换在灵感区上方，带重复统计和采购按钮 | 移至灵感区下方、周历正上方，移除该行已安排统计和采购预览按钮；周历下方完整清单入口保留 | 明确周切换与周历关系 |
| 周历星期、日期分两层 | 星期、日期和月份单行排版，日期头从 76px 收至 56px | 压缩日期头，保留日期衬线数字与今天提示 |
| 灵感标题附带操作说明 | 删除该说明 | 保留标题、搜索、轮播及拖拽操作 |
| 采购页调料提醒与日期区留白过多 | 周切换置于标题之后，调料提醒使用更紧凑内距、标题和内容间距 | 减少进入购物清单前的空白；四项缺货场景另有截图 |
| 已买项目默认混在待买列表 | 列表右上加入“显示已买”，默认不勾选；部分购买但仍有待买量的项目仍显示 | 只改变可见性，保留购买记录、统计和原有操作 |
| 采购标题旁跨周说明、列表后移除说明 | 删除这两处重复说明 | 保留日期、更新计划需求及原恢复行为 |
| 标语使用本轮新设 17px 字体 | 恢复初版 Georgia／STSong／SimSun 字体栈、21px、1.65 行高、2px 字距，原窄窗口回落保留 | 根据用户偏好恢复最初排版 |

## 验证和截图

- TypeScript、ESLint、前端构建及 Windows EXE／NSIS 打包通过。
- 本轮 40 项既有与更新用例最终均通过，另新增四项调料缺货布局用例通过：共 41 项。涵盖菜谱列数、分类、库存筛选／轮播、周历拖放／失败恢复、采购及已买显隐、窗口布局与抽屉。
- 初跑中的采购计算失败用例因测试辅助函数等待不存在的“显示已买”而超时，已修正测试辅助函数只在成功加载列表时勾选，原失败状态断言保留；该用例单独复测通过。未用放宽断言处理。
- 浏览器布局覆盖 1000、1280、1440、1920；部分库存操作含 2560。窗口宽度测试不代表多档 Windows 系统缩放全部验收。
- Windows WebView2 隔离检阅器检查普通窗口及最大化，保留四张最大化截图。使用当前应用前端组件与内存演示数据，检阅器关闭原生数据桥接并通过父窗口传递最大化状态；没有读写个人厨房。这是原生渲染检查，不替代真实数据库端到端验收。
- 上轮发现的导入食材内容回归不在本轮改动范围，未重新验证，不能视为已解决。
