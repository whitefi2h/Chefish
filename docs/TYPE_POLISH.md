# 思源黑体排版微调

2026-11-01。依据用户选定的第 10 组：思源黑体，Semibold 标题和强调，Medium 正文。此轮已应用到主程序；功能和数据逻辑不变。

| Before | After | Why |
| --- | --- | --- |
| 第 10 组菜名 18px、行高 1.55 | 菜谱卡片菜名 16px、行高 1.35 | 减少长菜名的视觉体积和双行断层 |
| 整页依赖默认行高 1.55 | 正文 15px / 1.45，密集列表约 1.35 | 区分阅读内容与数据列表 |
| 库存行内边距 10px，批次说明间距 4px | 边距 8px，说明间距 2px | 使名称、日期与数量处于紧凑且清晰的一行 |
| 采购标题固定 22px 高，头像 32px | 取消固定标题高度，头像居中，文字统一左边线 | 防止头像侵入说明行，减少错位 |
| 首页右栏行内边距 14px、入口上距 17px | 行内边距 10px、入口上距 10px | 降低连续项目的松散感 |
| 食材右侧调料行多层上下留白 | 行内边距 6px、外距 2px | 名称、图标与行内操作保持同一节奏 |

字体采用 Adobe 原始 Source Han Sans CN VF，未改字形；许可 SIL OFL 1.1 位于 public/fonts/SourceHanSans-License.txt，关于页同步更新。
