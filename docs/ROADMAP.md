# 后续开发方向

v1.0.0 之后的建议顺序，尚未承诺版本或开始实施；下一阶段需讨论确认。

1. **备份与恢复**：数据库一致快照与图片打包；选择路径、完整性校验、恢复预览、自动备份保留策略；恢复可回退，凭据不混入普通备份。
2. **食材名称统一**：可维护别名，完善番茄 / 西红柿等匹配；保留蒜头 / 蒜末等形态区别，避免错误合并，预览迁移影响。
3. **AI 长期偏好**：家庭人数、忌口、口味、厨具、时间预算可查看、编辑、删除，当前请求可覆盖默认偏好。
4. **AI 连续任务**：串起找菜、整理、保存、配餐和采购，解决新对象 ID 引用、分阶段确认、失败恢复和进度展示。
5. **导出与 Windows 交付**：菜谱与清单导出、正式安装包、升级卸载数据保留验收，再评估签名和自动更新。

图片导入、库存持久化、菜单采购烹饪闭环、AI 业务提案、聊天保存和调料管理已经实现，不再列作待开发；它们的稳定性修正应单独记录。
