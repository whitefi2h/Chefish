# UI 对齐与布局修正

2026-11-01，依据本轮七张实机截图的批注实施。业务计算、数据存储和 AI 服务未作修改。

| Before | After | Why |
| --- | --- | --- |
| 周切换独占灵感区下方整行，两侧控件分散 | 移至页面标题右侧，日期范围两侧紧邻前后周按钮，返回本周和日期输入高 32px；窄窗口整体换行 | 消除空行与横向大跨度，保留所有日期操作 |
| 星期、大号日期、月份排列生硬 | 日期数字在左，右侧以小字显示“10 月 · 周一”，今天另加文字提示 | 保留衬线日期，明确主次与对齐关系 |
| 首页上下网格使用不同列宽比例 | 两排使用相同列宽和间距，响应式断点同步 | 两排面板左右边界一致 |
| 缺货调料在首页底部独占通栏 | 并入下次采购，内部按可用宽度使用一列或两列，保留补齐与管理操作 | 采购事项集中；周安排面板不随采购内容增加而拉伸 |
| 迷你周历底部附带安排数量与库存说明 | 移除该段说明 | 减少重复解释 |
| 单行菜名顶对齐按钮，双行菜名视觉不同 | 标题区统一最小高度，单行／双行菜名和右侧按钮均垂直居中 | 同行视觉中线一致；宽屏四列、普通窗口三列规则保留 |
| 库存分类按钮文字显得偏下 | 明确固定高度、零垂直内距，并对文字上移 1px 作光学修正 | 思源黑体文字在按钮中更均衡 |
| 待买数、勾选框及显示已买文字基线不同 | 修正工具行被通用标题样式设置为 baseline 的问题，统一字体、行高并清除原生勾选框边距 | 文字中线与勾选框中心对齐 |

## 验证范围

- ESLint、TypeScript、前端构建通过。
- 33 项相关交互／布局用例通过：库存编辑和筛选、分类拖动、菜谱列数、菜单拖放及失败恢复、采购和已买显隐、四档窗口布局。最终调料分栏专项复测通过。
- 浏览器在 1000、1280、1440、1920 宽度留存页面截图；单独检阅长菜名、缺图、四项调料缺货、已买显隐。
- Windows WebView2 检查普通窗口和最大化，保留首页、周历、菜谱、库存、采购截图。使用隔离内存演示数据及当前应用组件，未读写个人厨房。绿色顶部工具条属于检阅器；菜谱检阅额外使用一个双行长名样本，图片为演示占位图。
- 原有导入食材内容回归问题不属于本轮修改范围，未声称解决；没有运行全项目测试或线上发布。
