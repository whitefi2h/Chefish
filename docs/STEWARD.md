# 厨房管家

V2.0.0 在现有助手中加入主动服务。进入左下角「我的厨房 → 厨房管家」，查看时间、餐次和自动补充权限，再开启「在这台电脑启用厨房管家」。升级不会自动开启，也不会自动注册开机启动。

默认每周六 18:00 询问下周菜单、每天 09:00 检查数据、每周三 18:00 推荐最多三道下厨房菜谱。时间按本机时区计算，可分别修改或关闭。

## 每周菜单

助手聊天区直接展示紧凑任务横幅，点击整条横幅进入独立会话。周末询问无人回复时保留等待，不重复催促。也可在顶部更多菜单中选择「规划本周菜单」或「规划下周菜单」。默认安排晚餐，可在设置选择常做餐次，再通过对话指定外食日、人数、口味和准备时间。

菜单草稿和对话保存在本机，跨天、跨重启继续。草稿不进入正式菜单，不改变采购需求，也不扣库存。每次对话返回完整的新草稿，原有正式安排默认保留。

先点击「核对菜单与采购」，查看安排差异及缺口，再确认写入正式菜单。确认时检查草稿版本、正式菜单和预览后的业务变化，失败时保留草稿。正式菜单已变化时，可保留对话并按最新菜单重新生成。重复确认不会重复添加菜。

即时助手的临时执行令牌与持久草稿分开；每周草稿没有二十分钟有效期。

任务会话与普通聊天分开保存，仅留本机。历史会话保留 30 天（按最近打开或回复计算），从顶部时钟图标进入「历史会话」，查看已处理任务；过期记录在下次读取时清理。未处理的菜单草稿继续保留；已结束菜单会话超过 30 天清理对话，已确认的正式菜单不受影响。

## 采购和估算

数量由后端统一计算，结合菜单人数、库存、已购买及已入库事实。明确同义词、明确单位可以归并；同类食材不会仅因相似就视为同一种。

「含估算」与「待核对」分别表示常见规格、模糊用量或库存粗略数量，以及尚不能准确抵扣的单位或包装。估算附原始用量及依据，不能当成包装实测净重。不同包装不会仅因都被规范为「盒」就直接互相抵扣。

在任务详情底部可保存已确认的别名和规格，规格按对应食材或产品名称使用。不同规格应分开命名；不会把某一种食材的换算套用到整个类别。旧数据丢失的原包装信息不能凭空还原，仍需按实际情况补充。

重新计算采购不会抹掉手动采购项、购买和入库记录。

## 每日整理

首次检查当前厨房，此后只处理内容发生变化的菜谱、食材和库存，复用现有食材用量整理及图片流程。可自动补分类、标签、图片，在授权范围内推测缺失库位和预计复查日期。

用户明确填写的分类、标签、真实到期日及库位优先。预计复查日期独立保存，不作为真实过期日期，也不触发自动丢弃或库存扣减。「未指定」库位可由管家推测填充；已有明确库位保留。

整理结果集中在任务卡片中，明细默认折叠，可修改标签、修正预计复查日期，或按批撤销。已有后续修改时拒绝覆盖式撤销。后台整理不占用普通 Ctrl+Z 撤销顺序。仅无法辨认的食材身份会集中提问，每次整理最多 3 项；缺少购买日期、开封状态或普通保存信息不会逐项追问。需要补充的事实可以在该任务的独立会话中说明，仍通过业务提案确认。

无变化、无新建议、无待办时不发送整理消息。

## 新菜谱

管家根据已有菜谱、库存、偏好和近期烹饪寻找搜索主题。先按来源链接和菜名排除已有及已推荐内容，同一批次中包含相同菜名的长标题也去重，再比较菜名、食材和做法，筛选有新意的菜式。

推荐保留来源、作者及推荐理由；搜索结果不冒充已读取的完整配方。点击「读取原文并整理」后走原有导入和确认保存流程；遇到站点限制时显示实际错误，不自动绕过验证。

## 运行、通知与免打扰

- 启用管家或开机自启动后，关闭窗口留在托盘。双击托盘图标（左键或右键双击事件）会显示、恢复最小化并聚焦主窗口；右键菜单也可选择「打开 Chefish」或「退出 Chefish」。
- 托盘右键菜单新增可勾选的「开机自启动」，与厨房设置中的「随 Windows 启动并留在托盘」同步。自启动独立于主动任务开关；启用后随 Windows 登录在后台启动，用户可随时取消。界面读取 Windows 实际注册状态。
- 电脑关机、睡眠或程序退出时不运行，恢复后只补检当前仍有效的一次任务，不补发过去多周的询问。
- 各功能分别有任务开关和通知开关。只关闭通知时继续工作，结果留在消息中。
- 免打扰暂停全部主动任务，包括后台用量整理和补图；用户手动调用不受影响。
- 网络失败按 5、30、120 分钟退避重试；配置或鉴权错误停止自动尝试，保留一条待办。修改模型设置后允许重新尝试。
- Windows 未显示系统通知时，应用内消息和未读数仍保留；不自动抢焦点。

## 多设备与备份

首版只在手动指定的一台电脑运行。切换设备前，先停用旧设备的管家并完成同步，再在新设备启用；不提供离线抢占或自动接管。

菜单、正式业务修改、标签、估算依据及确认的食材规则正常同步。消息、草稿、任务进度、自动修改的本机撤销凭据和管家设置不进入云同步与云快照。普通本地备份保留消息和草稿；恢复会暂停主动执行并清除旧调度及撤销凭据，草稿重新校验。

同步设备应一起升级至 V2.0.0。云端 schema 15 兼容规则的发布状态见[同步说明](CLOUD_SYNC.md)。

UI 沿用现有布局，视觉升级另行进行。
