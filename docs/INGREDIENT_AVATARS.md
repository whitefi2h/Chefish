# 本地食材头像接入

2026-10-30。彩色素材与文字兜底已接入应用，沿用 v2.0.0 版本号；没有提交、推送或替换线上 Release。

- 明确选择或上传的用户图片优先；旧自动照片默认使用彩色图标。本地展示和图片失败回落不修改库存、数量、菜单或图片数据。
- 首页、库存、调料、演示和原生采购列表使用同一个头像组件。
- 缺图使用本地彩色资源，剩余 12 项采用固定类别配色和名称首字。类别随机选择首次保存后稳定复用。
- 关闭后台自动网络照片补齐；保留用户明确要求的照片搜索。
- 设置的关于页与库存详情提供署名及许可；新 PNG 维持自定义许可的应用使用范围，不作为公共原素材包发布。

验证：类型检查、ESLint、35 项前端单元测试通过，13 项外部服务测试按原有条件跳过；新增头像界面回归 1 项和现有相关界面回归 14 项通过；原生图片模块 2 项本地测试通过，2 项真实模型／网络测试未启用。界面测试使用浏览器和隔离模拟数据，覆盖现有图优先、图形加载失败、文字兜底、刷新、1000px 窗口及许可入口，不等同于 Windows WebView2 的真实用户数据界面验收。

Windows release EXE 与 NSIS 安装包已成功构建。当前运行的旧版进程未终止，其原可执行文件保留为 `src-tauri/target/release/chefish-before-avatar.exe`；新构建为 `src-tauri/target/release/chefish.exe`。需退出旧版托盘进程后启动新版。

开发说明：[头像索引](../tools/ingredient-icons/README.md)。

## 旧照片遮盖图标修正

旧版本保存在 `ingredient.image` 的 Commons 照片没有记录自动／人工选择来源，不能一律视为用户指定图片。现在旧 Commons 照片默认不覆盖本地图标或文字头像，数据库原图不删除。用户在库存详情或调料区明确要求 AI 换图并成功后，本机保存明确选用照片的偏好；独立上传／其它来源的用户图片继续优先。来源和署名说明跟随当前展示方式。

回归覆盖“已有旧照片”的库存、调料和缺图食材，而非只测全新缺图数据；默认彩色图、文字兜底、用户自有图片及主动换图两项浏览器测试通过。新版 EXE 和安装包重新构建；旧进程使用的 EXE 保留为 `chefish-before-photo-priority-fix.exe`，未终止进程或修改个人厨房数据。

## 2026-10-31 首字头像

文字头像统一使用食材名称首字，包含未收录品类及图片失败回落；小头像 18px、详情大头像 40px。彩色图形匹配、用户照片选择及库存数据不受影响。8 项索引测试、应用界面回归和离线检阅检查通过；检查使用隔离演示数据。
