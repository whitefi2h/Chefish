# 初始化第二轮：紧凑引导

后续用户要求全程固定宽高，并将自由描述拆页；当前实现以 [固定外框与偏好分步](ONBOARDING_FIXED_FRAME_20261103.md) 为准。下文保留第二轮历史设计与证据。

问题依据：用户四张实机批注。上一轮只确认了流程可用，未满足窗口模式的内容密度、首次设置负担和完成反馈要求。

| Before | After | Why |
| --- | --- | --- |
| 820×780 固定大面板，欢迎页 logo 与标语占中心 | 欢迎 560×388、配置 680×552、完成 560×416 CSS px；始终受实际视口限制 | 窗口模式也保留外边距，减少无效空白 |
| 重复的大页头和七段进度 | 小品牌页头、五个实际配置步骤，欢迎与完成不算配置步骤 | 更快理解需要做什么 |
| AI 长框和所有偏好纵向堆叠 | 两列紧凑偏好，一句话填写按需展开 | 保留自由输入而不增加初始负担 |
| 初始化照搬管家完整设置 | 启用开关、三类任务选择、开机自启动；时间和通知留在原设置 | 只做首次关键决定 |
| 模型高级参数常态展开 | 服务/模型/密钥优先，高级参数折叠 | 减少填写量，复用保存机制 |
| 完成页大圆勾与五行状态表 | 动态勾选、用餐/风味/管家的实际摘要、单一进入按钮 | 给出可感知的完成反馈 |
| 深灰原生滚动条 | 浅色细滚动条，正文独立滚动 | 降低视觉干扰 |

配色沿用白色 #FFFFFF、画布 #F7F8F5、橙 #CF4818、浅橙 #FFF0E6、绿 #667C59、文字 #252B26。标题沿用思源黑体 Semibold 22px，正文 Medium/Regular 13px，辅助 12px；品牌沿用现有字标。签名元素是紧凑的“厨房设置清单”，展示真实配置与明确任务，删除独立大标语展示。

布局：小品牌头 → 轻进度 → 一句标题/说明 → 当前决策 → 固定前进/跳过。普通配置步骤保持同一高度；欢迎和完成缩小。切步 220ms 短距离横移淡入，完成勾描边约 400ms、摘要逐项淡入；减少动画与键盘切步不播放。

验收：全步骤正常/已配置/空白/失败状态，1000×700 到 1920×1080；额外按 Windows 实际 DPR 复核 CSS 视口，检查欢迎和完成无需滚动、固定操作区完整、管家不出现完整设置。原生隔离数据保存回归，录制完成动效。只修改初始化呈现与所需保存衔接，不改变调度、AI 提取、采购和同步规则。

## 实施与检阅结果

- 重写初始化自己的布局样式，不增加一层全局主题覆盖。仅模型设置新增可选的紧凑模式，原设置页保持完整控件；管家使用独立简版，保留原有详细设置值。
- TypeScript、ESLint 通过。相关浏览器交互 9 项通过：初始化 4、模型配置 1、通用设置 2、管家与自启动 2。数据使用合成 IPC/账户，覆盖保存失败保留输入、跳过不写入、已有配置、恢复进度等。
- 全部 7 个展示阶段在 571×400、1000×700、1280×800、1440×900、1920×1080 CSS 视口检查，共 35 张截图。欢迎和完成页无需滚动；配置内容超出时仅滚动正文，底部操作区保持可见。短视口不声称全部配置免滚动。
- Windows 原生检阅使用独立的 `com.chefish.onboardingqa` 数据目录。实际窗口 CSS 视口 854×534、最大化 1490×789，DPR 1.71875；已检查欢迎、偏好、精简管家和完成页。普通窗口管家正文高度与滚动高度均为 348px，欢迎均为 276px；最大化完成页均为 304px。个人厨房进程和数据未操作。
- 原生截图：[普通窗口欢迎](screenshots/onboarding-round2/native-window-welcome.png)、[普通窗口偏好](screenshots/onboarding-round2/native-window-preferences.png)、[普通窗口管家](screenshots/onboarding-round2/native-window-steward.png)、[最大化完成页](screenshots/onboarding-round2/native-maximized-finish.png)。尺寸数据以同名 JSON 保存；本地检阅证据不提交仓库。
- 完成动效另用浏览器合成数据录制，见 [引导与完成动效](screenshots/onboarding-round2/walkthrough.webm)。浏览器录像不当作 Windows 原生动效性能证据；原生已观察到进入完成页时勾选描边与摘要依次出现。
- Windows Release EXE、NSIS 安装包已重新构建，版本保持 2.0.0，未安装覆盖、提交、推送或替换 Release。真实云注册、模型提取及系统登录自启动不属于此次展示重构的重新联网验收范围。
