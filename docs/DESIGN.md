# 设计与交互约定

单用户 Windows 厨房应用，暖白底、陶土红主色、浅绿辅助色。模块共享 `src/tokens.css` 与 `src/styles.css`，不为 AI 另起视觉体系。

- 验证尺寸为 1280×800、1440×900、1920×1080；不能靠缩小字体或中文竖排塞入周历。
- 菜谱卡标签在图片左下角，周灵感按钮与菜名同排靠右，避免大块空白。
- 详情空间足够时为配料、过程、手记三栏，空间不足才让手记下移。
- 手记用独立居中弹窗编辑；步骤标题可编辑，不生成固定不可修改标题。
- 分类拖拽显示浮动行、占位和插入位置，统一保存；保留键盘辅助。
- 居中弹窗和侧边助手均不因外部点击或 Escape 意外关闭，使用 X 或明确操作关闭。正文独立滚动，背景位置保持。
- 调料侧栏紧凑；感叹号切换缺货，红色并配文字表示状态，再点取消；删除图标移出常备列表，不使用装饰性竖线。
- 提案展示具体餐次、日期、菜名、人数和补购，省去重复标题、空对比和技术说明，提供同意、拒绝和继续修改。
- 常规非库存成功操作保持安静，错误清楚显示；图标有可访问名称、键盘焦点与状态语义。

原始参考保留在开发者本地，运行时不依赖其 HTML、CDN 字体或远程占位图。
