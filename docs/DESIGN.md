# 设计与交互约定

单用户 Windows 厨房应用，浅灰绿底、明亮橙色主色、浅绿辅助色。模块共享 `src/tokens.css`、`src/styles.css` 与 `src/settings.css`，不为 AI 另起视觉体系。

- 页面底色 `#F7F8F5`、白色面板、侧栏 `#F2F4EF`，品牌橙 `#CF4818`；选中态采用 `#FFF0E6`，绿色 `#667C59` 与浅底 `#EDF3E8` 表示正常和完成，危险操作仍保留红色与文字。
- 仅 Chefish 字标保留原造型；正文、标题、菜名和日期统一 Windows 无衬线字体，数量和日期使用等宽数字。主面板圆角 18px、卡片 14px、控件 10px、标签 6px。
- 保留五个导航、主要面板位置、库存表格密度、七日周历及助手独立任务会话。视觉调整不改变业务逻辑、数据计算、AI 提示词、同步或调度。
- `public/brand.svg` 是统一品牌源，仅改为品牌橙和白色，路径、轮廓与透明边角保持。使用 `npx tauri icon public/brand.svg` 生成各尺寸应用图标。

- 验证宽度为 1000、1280、1440、1920；不能靠缩小字体或中文竖排塞入周历。库存表格与周历沿用内部横向滚动，页面本身不溢出。
- 菜谱卡标签在菜名下方、人数上方；封面不叠加标签。周灵感按钮与菜名同排靠右。标签采用菜系、菜品特性、烹饪方法三个维度，详细行为见 RECIPE_TAG_IMPLEMENTATION_20261101.md。
- 详情空间足够时为配料、过程、手记三栏，空间不足才让手记下移。
- 手记用独立居中弹窗编辑；步骤标题可编辑，不生成固定不可修改标题。
- 库存分类拖拽显示浮动行、占位和插入位置，统一保存；保留键盘辅助。菜谱标签使用独立的三维目录管理。
- 居中弹窗和侧边助手均不因外部点击或 Escape 意外关闭，使用 X 或明确操作关闭。正文独立滚动，背景位置保持。
- 调料侧栏紧凑；感叹号切换缺货，红色并配文字表示状态，再点取消；删除图标移出常备列表，不使用装饰性竖线。
- 提案展示具体餐次、日期、菜名、人数和补购，省去重复标题、空对比和技术说明，提供同意、拒绝和继续修改。
- 常规非库存成功操作保持安静，错误清楚显示；图标有可访问名称、键盘焦点与状态语义。

原始参考保留在开发者本地，运行时不依赖其 HTML、CDN 字体或远程占位图。
