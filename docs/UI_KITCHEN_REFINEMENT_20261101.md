## 数量与单位的使用边界

默认单位表位于 [ingredientDefaultUnits.json](../src/domain/ingredientDefaultUnits.json)，前端表单与助手上下文共同使用。用户给出明确单位时优先保留，表中默认值用于未指定单位的输入。

已有“洋葱 1g”不会自动改成“1 个”：程序不知道实际还剩多少。请在库存行点击“查看”，编辑批次的数量和库存单位。该操作属于记录纠正，不把旧数量自动换算，也不改写旧烹饪记录；历史流水保留当时的单位，撤销可还原纠正。

“用了半个青椒”表示 0.5 个；“剩下的青椒用了一半”才表示库存的一半。库存使用 g 而记录使用“个”时，现有单体重量表用于估算，并显示换算说明。实际大小仍以用户手动调整为准。库存不足时最多扣可用量，不能把错误旧记录反推成真实库存。
