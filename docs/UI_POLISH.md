# 界面视觉微调 · 2026-10-31

本轮参考《Chefish UI 视觉修改建议 V1.0》，以实际界面截图为准，减少重复边框，突出菜名与数量。保留橙绿配色、导航和主要面板，不修改业务逻辑。

| 调整前 | 调整后 | 原因 |
| --- | --- | --- |
| 菜谱封面偏宽，标题与副标题、操作挤在一起 | 封面改为 4:3，菜名独占内容区，灵感操作移入卡片底部 | 给食物和菜名更多空间；副标题仍在详情页显示 |
| 库存提醒外框、单项卡片重复描边 | 改为轻量提醒横栏，以分隔线收尾 | 提醒食材需要关注，避免整块页面变成警告色 |
| 数量、行内操作和状态均有较重底框 | 保留原控件尺寸，减轻数量与操作边框，突出食材名和状态文字 | 减少干扰，维持快速编辑的密度 |
| 缺货调料整行铺红 | 行背景恢复留白，缺货文字与图标继续提示 | 保留警示，避免侧栏喧宾夺主 |
| 周灵感面板套边框、空餐次重复虚线框 | 灵感横栏去外框，空餐次去默认虚线并缩短留白 | 七日周历和拖拽方式保持原样，减少无内容时的视觉重量 |
| 工具页顶部重复英文装饰 | 库存、周菜单和采购去掉英文眉题 | 将空间留给筛选、表格和计划 |

首页稍加强下一餐图片与标题；菜谱详情扩大主图。标题字号集中到共享变量，沿用系统字体，不新增字体下载。用户照片、步骤图片和食材头像规则保持原样。
