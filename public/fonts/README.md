Chefish uses MiSans fonts from Xiaomi's original download package.
Source: https://hyperos.mi.com/font-download/MiSans.zip
Licence: MiSans-License.pdf (unchanged publisher agreement).

The historical MiSans review uses unmodified static WOFF2 files with semantic CSS weight matching:
Light -> CSS 300; Regular -> CSS 400; Medium -> CSS 500;
Semibold -> CSS 600; Bold -> CSS 700.

The original variable font has a nonstandard wght axis of 150..700.
Its named Regular instance is 330, Light is 250, and 700 is Heavy.
Do not replace these static files with that variable file under a 100..900 descriptor.
The original variable file is kept in the local docs/fixtures/fonts cache for historical comparison, not bundled with the app.
