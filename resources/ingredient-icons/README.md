# 食材头像索引 v0.1.0

[index.json](index.json) 是名称、别名、候选图形、选图限制的唯一数据源。

- 131 项食材：64 项精确图形、55 项类别代用、12 项文字头像。
- 118 张 SVG（包括禁止误用及仅供参考样例），20 张新增彩色 PNG，覆盖原待补项中的 18 类食材。
- 全部条目仍保留人工检阅状态；不会因开发者挑过图就自动认可用户的检阅结论。
- 仅使用彩色候选。类别图首次随机分配后固定；用户指定图片或人工选图优先。
- 文字头像统一显示食材名称去掉首尾空白后的首字；无合适图形或图形加载失败时，按类别固定配色显示文字头像。
- 选图不参与食材合并、库存扣减、单位换算或安全判断，已接入应用的食材头像展示。

参见 [开发说明](../../tools/ingredient-icons/README.md)、[彩色补缺记录](../../tools/ingredient-icons/ASIAN_SOURCES.md)。

自定义许可 PNG 的本机缓存 `local/` 与生成的检阅 HTML 均不加入 Git，以免公开为可复用素材包。重新准备本机检阅时，运行 `node tools/ingredient-icons/build.mjs fetch`，再运行 `node tools/ingredient-icons/build.mjs build`。

## 应用接入

Vite 开发启动和构建时通过 `prepare-app.mjs` 生成精简运行时索引与本地应用资源；类型检查前也生成索引。新检出目录先运行 `node tools/ingredient-icons/build.mjs fetch` 准备自定义许可原图缓存。生成目录不加入公共源码，安装包内包含应用展示资源和许可记录。

共享 `IngredientAvatar` 覆盖首页、库存、常备调料以及演示／原生采购列表。明确选择或上传的用户图片优先；旧版自动抓取的 Commons 照片默认改用本地彩色候选，类别候选首次随机分配后按食材身份保存在本机。图片失败时依次回落本地图形和固定配色文字头像，不更改食材记录。未知名称也使用首字，仅空名称显示“食”。

“设置 → 关于 Chefish”可查看素材作者与许可；库存详情也展示所用本地图形来源。后台自动网络照片补齐停止，用户显式“让 AI 换张图片”的操作仍保留。

旧 Commons 照片的默认展示已切换为彩色图标／文字头像；只有用户明确换图成功后才优先使用对应照片，原照片数据保留。
